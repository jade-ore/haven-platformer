# Haven Platformer
This Godot game was made for Haven Jumpstart! It is a really simple game that is just a short platformer where everything is Daven.

# Features
It includes gravity and infinite jump (pro feature)
The end screen teleports you back to the start where you can play this fun game again

# Struggles
There kinda weren't any, since I've had experience working with Godot and it is just a platformer. If anything it was just me adding semicolons on accident because I've been working on a C++ project.
